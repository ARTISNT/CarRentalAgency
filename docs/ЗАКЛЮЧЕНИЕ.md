# ЗАКЛЮЧЕНИЕ

В ходе работы над дипломным проектом на тему «Разработка веб-ресурса для агентства по аренде автомобилей с поддержкой многопользовательской работы» были получены следующие результаты.

Выполнен анализ предметной области и определена актуальность разработки веб-ресурса для агентства по аренде автомобилей. Было установлено, что небольшие агентства нуждаются в программном средстве, которое позволяет централизованно управлять автопарком, контролировать бронирования, формировать договоры аренды, обрабатывать платежи, вести учёт клиентов и шаблонов документов, а также разграничивать права доступа пользователей. Особое внимание было уделено проблемам малого бизнеса в сфере проката автомобилей: разрозненному учёту транспортных средств, отсутствию онлайн-бронирования, сложности формирования юридически значимых договоров, ручной обработке платежей, отсутствию прозрачного контроля статусов автомобилей и недостатку автоматизации уведомлений.

Проведён анализ существующих решений и подходов к автоматизации деятельности агентств по аренде автомобилей. В ходе анализа были рассмотрены возможности типовых веб-сайтов агентств проката, их преимущества и ограничения. На основании проведённого исследования были сформулированы требования к разрабатываемому программному средству: поддержка многопользовательской работы с разграничением прав доступа, управление автопарком с контролем состояний автомобилей, создание и сопровождение бронирований, расчёт стоимости с применением промокодов и скидок, формирование договоров аренды с электронным подписанием, интеграция с платёжным шлюзом, отправка уведомлений по электронной почте, журнал аудита действий пользователей и возможность контейнерного развёртывания.

Разработана архитектура программного средства. Серверная часть реализована в виде набора микросервисов на ASP.NET Core с применением принципов Clean Architecture и разделения ответственности по границам предметных областей (DDD). В системе выделены六个 микросервисов: CarService (управление автопарком), UserService (аутентификация и пользователи), RentalService (бронирования и ценообразование), ContractService (договоры и шаблоны), PaymentService (платежи через bePaid), NotificationService (email-уведомления). Для межсервисного взаимодействия используется RabbitMQ через MassTransit. Единой точкой входа выступает API Gateway на основе Ocelot. Для хранения данных используется Microsoft SQL Server 2022 (отдельная база данных на каждый микросервис). Клиентская часть реализована как одностраничное веб-приложение на React 19 с использованием TypeScript, Vite, Ant Design 6 и TanStack React Query. Для развёртывания системы подготовлена Docker-инфраструктура в docker-compose.yml, обеспечивающая запуск всех микросервисов, баз данных, RabbitMQ и API Gateway в едином контейнерном окружении.

Реализован функционал авторизации и регистрации пользователей. В системе предусмотрена регистрация с указанием имени, фамилии, адреса электронной почты, номера телефона и пароля. После регистрации пользователь может выполнить вход с получением JWT-токена. Реализована двухсхемная JWT-аутентификация: UserAuth для конечных пользователей и InternalAuth для межсервисного взаимодействия. Подтверждение адреса электронной почты осуществляется через верификацию в системе. Также реализована возможность добавления паспортных данных пользователя, используемых при формировании договоров аренды.

Реализована поддержка многопользовательской работы. В системе предусмотрены три роли: Client (клиент), Manager (менеджер) и Admin (администратор) с 27 различными правами доступа. Администратор может создавать пользователей, назначать им роли, активировать и деактивировать учётные записи. Разграничение прав доступа позволяет контролировать доступ к просмотру, созданию, изменению и удалению данных в каждом модуле системы.

Реализован модуль управления автопарком. Пользователь с соответствующими правами может создавать, редактировать и удалять автомобили, указывая полные характеристики: марку, модель, поколение, вариант кузова, цвет, государственный номер, VIN-код, год выпуска, пробег, тип трансмиссии, тип привода, объём двигателя, тип кузова, класс и цену за час аренды. Для каждого автомобиля автоматически контролируется состояние с помощью формальной машины состояний. Автомобиль может находиться в состояниях: Available (доступен), Rented (арендован), Reserved (зарезервирован), Maintenance (на обслуживании) или Broken (неисправен). Система предотвращает недопустимые переходы между состояниями и обеспечивает целостность данных автопарка.

Реализован модуль бронирования и аренды. Пользователь может создать бронирование с выбором автомобиля, дат начала и окончания аренды. Система автоматически рассчитывает предварительную стоимость на основе почасовой цены и длительности аренды. Поддерживаются промокоды и правила скидок: скидка 5 % при аренде от 24 часов, 10 % при аренде от 48 часов, а также скидки по промокодам WELCOME2026 (15 %) и LOYALTY_OFFER (20 %). Максимальная скидка ограничена 50 %. Фоновые службы RentalActivationService и RentalExpirationService автоматически активируют запланированные аренды и обрабатывают истёкшие бронирования.

Реализован модуль договоров и шаблонов документов. Система формирует договоры аренды на основе HTML-шаблонов трёх типов: Contract (договор аренды), ReturnAct (акт возврата) и Addition (дополнительное соглашение о продлении). Для шаблонов поддерживается версионирование, переименование, редактирование содержимого, активация и деактивация. При создании договора система создаёт снимок шаблона, обеспечивая неизменность документа даже при последующем изменении шаблона. Реализована электронная подпись с использованием графического ввода (Signature Canvas). Подписанный договор сохраняется в формате PDF и доступен для скачивания.

Реализована интеграция с платёжным шлюзом bePaid. Система поддерживает депозитные платежи (залог), полную оплату стоимости аренды и возврат депозита. Платежи обрабатываются через внешний шлюз с использованием вебхуков для получения статуса транзакции. Статусы транзакций: Pending (ожидание), Success (успешно), Failed (ошибка). После успешной оплаты пользователь перенаправляется обратно в систему через callback-URL.

Реализован модуль уведомлений. Система отправляет email-уведомления при наступлении значимых событий: создание бронирования, завершение аренды, продление аренды, создание договора, подписание договора, завершение договора. Уведомления отправляются через SMTP-сервер, а также дублируются в консоль. Обработка событий осуществляется асинхронно через RabbitMQ, что обеспечивает отказоустойчивость и масштабируемость.

Реализован журнал аудита. На каждое значимое действие система генерирует доменные события (Domain Events), которые фиксируются и могут быть использованы для анализа действий пользователей. Интеграционные события публикуются в RabbitMQ и потребляются соответствующими микросервисами. Это позволяет отслеживать полную историю изменений состояния системы.

Разработан адаптивный пользовательский интерфейс. Frontend-приложение содержит следующие страницы: главная страница (Landing), каталог автомобилей, карточка автомобиля, страницы регистрации и входа, список аренд, карточка аренды, создание аренды, страница оплаты и callback, список договоров, подписание договора, профиль пользователя с паспортными данными, а также панели администратора для управления автомобилями, арендами, договорами, шаблонами и пользователями. Интерфейс реализован с использованием Ant Design, поддерживает адаптивную вёрстку, содержит таблицы с фильтрацией, модальные окна, формы с валидацией, уведомления об ошибках и механизмы обработки состояний загрузки.

Выполнено тестирование программного средства. Реализованы автоматизированные API integration tests с использованием xUnit, WebApplicationFactory, Testcontainers и Respawn. Тесты проверяют корректность работы ключевых сценариев системы.

Выполнено экономическое обоснование разработки программного средства. На основании расчётов определена полная себестоимость разработки веб-ресурса. Рассмотрены возможные схемы монетизации программного продукта, среди которых наиболее целесообразной является Freemium-модель: бесплатное использование для автопарков до 10 автомобилей, платная Pro-подписка для неограниченного автопарка с расширенной аналитикой и AI-ценообразованием, а также транзакционная комиссия 2-5 % через платёжный шлюз bePaid и партнёрская CPA-модель со страховыми и обслуживающими компаниями.

Практическая значимость разработанного программного средства заключается в том, что веб-ресурс может быть использован агентствами по аренде автомобилей различного масштаба — от небольших локальных прокатов до сетевых компаний — для управления автопарком, приёма онлайн-бронирований, автоматического формирования договоров, обработки платежей и уведомления клиентов. Система позволяет централизовать данные об автопарке, повысить прозрачность бизнес-процессов, автоматизировать документооборот, снизить вероятность ошибок при оформлении аренды и улучшить взаимодействие с клиентами.

Новизна проекта заключается в разработке веб-ресурса, объединяющего в едином приложении микросервисную архитектуру с разделением по границам предметных областей, формальную машину состояний для управления жизненным циклом автомобилей, интеграцию с платёжным шлюзом bePaid, формирование договоров с электронным подписанием на HTML-шаблонах с версионированием, двухсхемную JWT-аутентификацию для пользователей и межсервисного взаимодействия, асинхронную коммуникацию через RabbitMQ/MassTransit, и контейнерное развёртывание через Docker Compose. В отличие от простых сайтов агентств проката, разработанное программное средство поддерживает полный цикл аренды: от управления автопарком и онлайн-бронирования до электронного подписания договоров и обработки платежей, с разграничением прав доступа и автоматическими уведомлениями на всех этапах.

Таким образом, цель дипломного проекта достигнута. В результате работы разработан веб-ресурс для агентства по аренде автомобилей с поддержкой многопользовательской работы, обеспечивающий автоматизацию основных процессов агентства, разграничение прав доступа, централизованное хранение данных, асинхронное уведомление пользователей, контроль действий сотрудников и возможность дальнейшего развития программного продукта.
