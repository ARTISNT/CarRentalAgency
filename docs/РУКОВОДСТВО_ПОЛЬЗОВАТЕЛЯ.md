# ПРИЛОЖЕНИЕ 4. Руководство пользователя CRM-системы агентства по аренде автомобилей

## Введение

Приложение предназначено для автоматизации работы агентства по аренде автомобилей. Система позволяет управлять автопарком, создавать и сопровождать бронирования, формировать договоры аренды с электронным подписанием, обрабатывать платежи через платёжный шлюз, управлять шаблонами документов, а также вести учёт пользователей с разграничением прав доступа.

Пользователь может просматривать каталог доступных автомобилей с подробными характеристиками, создавать бронирования с выбором дат и промокодов, подписывать договоры электронной подписью, оплачивать аренду, отслеживать статусы своих аренд и договоров. Для администраторов предусмотрены панели управления автопарком, арендами, пользователями и шаблонами документов.

Для начала работы необходимо зарегистрироваться в системе. На странице регистрации пользователь указывает имя, фамилию, адрес электронной почты, номер телефона и пароль. После заполнения всех обязательных полей необходимо нажать кнопку регистрации. После успешной регистрации пользователь может выполнить вход в систему.

---

## Страница регистрации пользователя

На странице регистрации отображаются поля для ввода имени, фамилии, отчества, адреса электронной почты, номера телефона и пароля. Также доступна ссылка для перехода на страницу входа, если у пользователя уже есть учётная запись.

Для создания учётной записи необходимо заполнить все обязательные поля и нажать кнопку «Зарегистрироваться». После успешной регистрации система создаёт учётную запись пользователя и перенаправляет на страницу входа.

## Страница входа в систему

На странице входа отображаются поля для ввода адреса электронной почты и пароля. После ввода данных необходимо нажать кнопку «Войти». Если пользователь забыл пароль, функция восстановления доступа на текущем этапе не реализована и требует ручного сброса администратором.

При успешной аутентификации система формирует JWT-токен, который используется для авторизации всех последующих запросов. В зависимости от роли пользователя (Client, Manager, Admin) определяются доступные разделы и действия. После входа пользователь перенаправляется на главную страницу системы.

*Рисунок П4.2 – Страница входа в систему*

## Главная страница — каталог автомобилей

После входа пользователь попадает на страницу каталога автомобилей. На ней отображаются все доступные автомобили в виде карточек. Для каждого автомобиля показывается фотография, марка, модель, класс (Economy, Standard, Business, Premium), цена за час аренды, цвет и текущий статус доступности.

В верхней части страницы расположены поле поиска и фильтры, позволяющие отфильтровать автомобили по классу, статусу доступности и другим характеристикам. При нажатии на карточку автомобиля пользователь переходит на страницу подробной информации.

Для просмотра только доступных автомобилей без авторизации предусмотрена публичная версия каталога, доступная по прямой ссылке.

## Карточка автомобиля

На странице карточки автомобиля отображаются подробные сведения о выбранном транспортном средстве: фотография, марка, модель, поколение, вариант кузова, цвет, государственный номер, VIN-код, год выпуска, технические характеристики (пробег, тип трансмиссии, тип привода, объём двигателя, ёмкость топливного бака, тип кузова), класс автомобиля и цена за час аренды.

Также отображается текущий статус доступности автомобиля (Available, Rented, Reserved, Maintenance, Broken). Если автомобиль доступен, отображается кнопка «Арендовать», при нажатии на которую пользователь переходит к созданию бронирования.

## Страница создания аренды

На странице создания аренды пользователь выбирает дату и время начала и окончания аренды, указывает промокод (при наличии) и просматривает предварительный расчёт стоимости. Система автоматически рассчитывает стоимость на основе цены за час аренды и длительности бронирования.

При указании промокода система применяет скидку в соответствии с правилами. Поддерживаются скидки за длительность аренды (5 % при аренде от 24 часов, 10 % при аренде от 48 часов) и скидки по промокодам. Максимальный размер скидки ограничен 50 %.

Для завершения создания аренды необходимо нажать кнопку «Забронировать». После создания аренда получает статус «AwaitingConfirmation». Система также создаёт запись о платеже с рассчитанной предварительной суммой.

*Рисунок П4.5 – Страница создания аренды*

## Страница «Мои аренды»

На странице «Мои аренды» отображается список всех аренд текущего пользователя. Для каждой аренды показываются: марка и модель автомобиля, дата начала и окончания, текущий статус, предварительная стоимость и дата создания.

Список поддерживает фильтрацию по статусу и дате. Возможные статусы аренды: AwaitingConfirmation (ожидает подтверждения), Scheduled (запланирована), Active (активна), Completed (завершена), Cancelled (отменена).

При нажатии на запись аренды пользователь переходит на страницу подробной информации. Для каждой аренды доступны действия: отмена (для активных аренд) и переход к оплате.

*Рисунок П4.6 – Страница «Мои аренды»*

## Карточка аренды

На странице карточки аренды отображаются подробные сведения: информация об автомобиле (марка, модель, цвет, госномер), информация о пользователе (ФИО, телефон, email), даты начала и окончания аренды, текущий статус, стоимость, применённый промокод и размер скидки, статус оплаты депозита и полной оплаты.

Пользователь может выполнить следующие действия в зависимости от статуса аренды:
- **AwaitingConfirmation** — отменить аренду;
- **Active** — завершить аренду досрочно или продлить;
- **Completed** — просмотреть итоговую сумму.

Также отображается статус подписания договора и оплаты. Если договор ещё не подписан, отображается соответствующая ссылка.

*Рисунок П4.7 – Карточка аренды*

## Страница оплаты

Страница оплаты интегрирована с внешним платёжным шлюзом bePaid. Пользователь может выполнить два типа платежа: депозитный платёж (залог) и полная оплата стоимости аренды.

Для оплаты необходимо нажать кнопку соответствующего типа платежа. Система перенаправляет пользователя на страницу платёжного шлюза bePaid, где необходимо ввести платёжные данные. После успешной оплаты платёжный шлюз перенаправляет пользователя обратно в систему.

Статусы транзакций: Pending (ожидание), Success (успешно), Failed (ошибка). Для депозитных платежей после завершения аренды доступна функция возврата депозита.

*Рисунок П4.8 – Страница оплаты*

## Страница договоров

На странице договоров отображается список всех контрактов текущего пользователя. Для каждого договора показываются: номер договора, статус, дата создания и дата подписания. Возможные статусы договора: AwaitingSignature (ожидает подписания), Active (активен), Ended (завершён), Cancelled (отменён).

При нажатии на запись договора пользователь может просмотреть его детали. Для договоров со статусом «AwaitingSignature» доступна кнопка перехода к подписанию. Для подписанных договоров доступна функция скачивания PDF-копии.

*Рисунок П4.9 – Страница договоров*

---

## Модуль подписания договора

На странице подписания договора отображается содержимое договора, сформированное на основе выбранного шаблона документа. Для подписания пользователь должен поставить электронную подпись с помощью графического планшета или мыши в специальной области для рисования подписи.

После нанесения подписи необходимо нажать кнопку «Подписать договор». Система сохраняет изображение подписи, прикрепляет его к договору, формирует итоговый PDF-документ с подписью и переводит договор в статус «Active». Готовый PDF-документ доступен для скачивания в любой момент.

*Рисунок П4.10 – Модуль подписания договора*

## Страница шаблонов документов

Раздел предназначен для управления шаблонами, используемыми при формировании договоров и сопутствующих документов. На странице отображается таблица со списком шаблонов, их названиями, версиями, типом документа, статусом активности и датой создания.

Система поддерживает три типа шаблонов документов:
- **Contract** (Договор аренды) — основной шаблон договора;
- **ReturnAct** (Акт возврата) — шаблон акта приёма-передачи при возврате автомобиля;
- **Addition** (Дополнительное соглашение) — шаблон для продления договора.

Для создания нового шаблона необходимо нажать кнопку «Создать шаблон», указать название, выбрать тип документа и ввести содержимое шаблона в формате HTML. Для существующих шаблонов доступны действия: редактирование содержимого, переименование, активация и деактивация. При создании договора система использует активные шаблоны, указанные в конфигурации.

## Страница профиля пользователя

На странице профиля пользователь может просматривать и редактировать свои личные данные: имя, фамилию, отчество, адрес электронной почты и номер телефона. Также доступен раздел паспортных данных, где необходимо указать серию и номер паспорта, идентификационный номер, дату выдачи паспорта и дату рождения.

Паспортные данные используются при формировании договора аренды для идентификации сторон. Для сохранения изменений необходимо нажать кнопку «Сохранить».

## Панель управления автопарком

Раздел предназначен для администраторов и менеджеров и позволяет управлять автопарком организации. На странице отображается таблица всех автомобилей с указанием марки, модели, цвета, государственного номера, VIN-кода, класса, цены за час аренды и текущего статуса.

При нажатии на кнопку «Добавить автомобиль» открывается форма, в которой необходимо указать все характеристики транспортного средства: марку, модель, поколение, вариант кузова, цвет, госномер, VIN-код, год выпуска, тип трансмиссии, тип привода, объём двигателя, пробег, тип кузова, класс, цену и фотографию.

Автомобиль может находиться в одном из следующих состояний: Available (доступен), Rented (арендован), Reserved (зарезервирован), Maintenance (на обслуживании), Broken (неисправен). Для изменения статуса автомобиля используются соответствующие кнопки в карточке: «Отметить как арендованный», «Вернуть», «Отправить на обслуживание», «Отправить в ремонт», «Завершить обслуживание». Система контролирует допустимость переходов между статусами, предотвращая некорректные изменения.

## Панель управления арендами

Раздел предназначен для просмотра и управления всеми арендами системы. Администратор может просматривать аренды всех пользователей, фильтровать их по статусу, пользователю, автомобилю и дате. В таблице отображаются ФИО арендатора, марка и модель автомобиля, даты аренды, статус и стоимость.

Администратор может изменять статус аренды: подтверждать бронирования, отмечать начало и завершение аренды, отменять бронирования. Также доступна информация о статусе оплаты и подписания договора по каждой аренде.

*Рисунок П4.14 – Панель управления арендами*

---

## Панель управления пользователями

Раздел предназначен для управления учётными записями пользователей системы. Администратор может просматривать список всех пользователей с указанием ФИО, адреса электронной почты, номера телефона, роли и статуса активности.

Для каждого пользователя доступны следующие действия: активация и деактивация учётной записи, изменение роли. Система поддерживает три роли: Client (клиент), Manager (менеджер) и Admin (администратор). Роли определяют набор прав доступа:

- **Client** — просмотр каталога, создание и просмотр своих аренд, подписание договоров;
- **Manager** — все права Client, а также управление автопарком, просмотр всех аренд, работа с шаблонами;
- **Admin** — все права Manager, а также управление пользователями и смена ролей.

## Окно профиля и выхода из системы

Для выхода из системы пользователь открывает меню профиля в верхней части страницы и нажимает кнопку «Выйти». В этом же меню доступны просмотр и редактирование профиля, а также смена пароля. После выхода пользователь перенаправляется на страницу входа в систему, а JWT-токен удаляется из локального хранилища браузера.
